# Демо «Агент» — замена Linko (v0)

Статическое демо мобильного приложения торгового агента. Не боевая система.
Данные: товары/цены/остатки — реальные публичные из каталога Vicon; магазины, агенты, долги, заказы — выдуманные.
Состояние хранится в браузере (localStorage), «сервер» имитируется api.js.

Вход: agent1 / agent2 / agent3 / super / admin / boss, пароль 1234.
Сброс демо-данных: «Ещё» → «Сбросить демо-данные».

Проверка: `python3 tests/full.py` (Playwright, 390×844, 20 проверок по SPEC.md).
Спецификация: ../SPEC.md. Исследование: ../research/.
